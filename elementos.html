Seleção de Elementos

A seleção de elementos no DOM em JavaScript funciona como uma ponte para encontrar nós HTML na árvore da página e poder manipulá-los.

Criação de Elementos

A criação de elementos no DOM com JavaScript funciona em três passos principais: criar o elemento na memória, configurar seu conteúdo ou atributos e inserir o elemento na página.
