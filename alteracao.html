Alteração de textos


A alteração de textos no DOM com JavaScript consiste em localizar um elemento HTML e modificar o conteúdo dele através de propriedades como textContent, innerText ou innerHTML.


Alterando texto com textContent
' < p id="mensagem" >Olá, mundo!< /p > '


innerHTML
A diferença fica clara:


elemento.innerHTML = "< strong>Olá!< / strong >";


faz o navegador interpretar o HTML, resultando em: Olá! Por isso, innerHTML deve ser usado com cuidado quando o conteúdo vem de usuários ou de fontes não confiáveis, pois pode introduzir HTML/JavaScript indesejado.

Alteração de estilo

A alteração de estilo no DOM com JavaScript funciona selecionando um elemento HTML e modificando diretamente o seu atributo inline style ou alterando as suas classes CSS.

Como alterar o estilo inline com a propriedade style


Você pode mudar o estilo de um elemento acessando a propriedade .style do objeto correspondente no DOM.


Seleção: Primeiro, você encontra o elemento usando métodos como document.getElementById ou document.querySelector


Modificação: Você chama .style seguido da propriedade de estilo desejada.


Nomenclatura (CamelCase): Nomes de propriedades CSS com hífen (como background-color) perdem o hífen e usam letra maiúscula na palavra seguinte (backgroundColor).

Exemplo Pratico

" const meuBotao = document.getElementById("botao"); meuBotao.style.backgroundColor = "blue"; meuBotao.style.color = "white"; "
