qual a relação entre os dois?

O HTML é o que o servidor retorna na resposta da requisição, é analisado e o DOM (Document Object Model) é o que o navegador constrói a partir dele e que pode ser manipulado com JavaScript. Isso faz uma enorme diferença na organização e funcionamento


em resumo o DOM cria uma interação por Hierarquia dentro das estruturas do HTML apartir disso o servidor tem mais acesso e organização quando se trata das estruturas de configuração e funcionamento

como o JavaScript acesa esses Elementos

O JavaScript acessa os elementos do HTML justamente apartir do DOM ja que os dois deixam a estrutura mais funciona
